**Laravel 12 REST API with Sanctum**

A simple REST API built with Laravel 12 and Laravel Sanctum for token-based authentication.

This project demonstrates how to build a secure Laravel REST API with user registration, login, logout, and protected API routes.

**Features**

User registration

User login

Laravel Sanctum token authentication

Protected API routes

Get authenticated user

User logout

REST API structure

MySQL database support

API testing with Postman or Thunder Client

**Requirements**

PHP 8.2 or higher

Composer

Laravel 12

MySQL

Node.js and NPM

Postman or Thunder Client
